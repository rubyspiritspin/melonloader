# MelonLoader

### Universal Unity game mod loader

MelonLoader is one of the most widely used mod loaders for Unity games. It supports both mono and IL2CPP games, providing a stable foundation for mod development in games like VRChat, Among Us, Gorilla Tag, and more.

<br>

---

## Features

| | |
|:---|:---|
| **Mono & IL2CPP** | Supports both major Unity scripting backends used in modern games |
| **Unhollower** | Automatically generates wrapper assemblies for IL2CPP game modding |
| **Plugin Architecture** | Clean API for writing mods that interact with any Unity game |
| **Active Community** | Large ecosystem of mods and developer tooling built around the loader |
